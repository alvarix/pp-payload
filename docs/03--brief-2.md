# Overview

This Payload site is intended to function as both a content platform and an operational backend, unifying various aspects of my business. It replaces prior workflows consisting of Google Spreadsheets, Mailchimp Email, WordPress Front End and Obsidian lead tracking.

⸻

# Data Objects
- **Clients**
  - replaces:
    - Google Spreasheet - Client data
    - Mailchimp - client email list
- **Jobs**
  - replaces:
    - Google Spreasheet - job status 
- **Events**
  - will replace:
    - Wordpress Tribe Events Plugin
  - connects Collaborators (Leads) - Clients - Jobs
- **Leads**
  - Prospects and Collaborators
